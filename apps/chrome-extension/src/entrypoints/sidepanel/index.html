Setup Required

Install the summarize CLI and start the daemon:

1. Install CLI:

npm i -g @steipete/summarize

2. Start daemon with token:

summarize daemon install --token loading...

3. Verify:

summarize daemon status

Navigate to a YouTube, TikTok, or Instagram Reel to extract transcript.

Supported URLs:
- youtube.com/watch, /shorts, /live
- youtu.be short links
- tiktok.com videos
- instagram.com/reel, /p, /tv
